# SGCAE – Sistema de Gestión y Control de Acceso de Empleados

## Descripción
Sistema desarrollado en C# y .NET 10 para gestionar empleados, credenciales y controlar el acceso a diferentes áreas de una organización.

## Funcionalidades
- Gestión de empleados.
- Asignación y bloqueo de credenciales.
- Administración de puntos de acceso.
- Registro de entradas y salidas.
- Consulta del historial de accesos.

## Tecnologías
- C# y .NET 10
- ASP.NET Core Web API
- SQL Server
- Entity Framework Core
- Clean Architecture, DDD y CQRS
- MSTest

## Ejecución
1. Abrir `SGCAE.slnx` en Visual Studio.
2. Configurar la conexión a SQL Server.
3. Aplicar las migraciones de Entity Framework Core.
4. Ejecutar `SGCAE.Api`.
